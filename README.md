# 高中地理知识库

纯静态、无后端的高中地理考点库：左侧章节树、中间卡片、右侧详情的三栏阅读面。支持检索、类型/难度/状态筛选、笔记、掌握状态、复习记录、易混对照、配套例题、地理学发展年表、JSON / CSV / Markdown 备份与 Service Worker 离线。

视觉为深海蓝 Hero + 暖纸阅读面 + 蓝灰玻璃，明暗双主题同构；全部用户数据只存在本机浏览器，与教材内容严格分离。

## 内容

- 人教版（2019）五本书 · 65 课 · 139 条考点卡
  - 必修第一册 39 条 · 必修第二册 31 条 · 选择性必修1 34 条 · 选择性必修2 18 条 · 选择性必修3 17 条
- 278 道配套例题：每条考点各 2 道同型题，挂在对应考点卡详情中，含题干、小问、答案、解析与思路
  - 第 2 道为变式题，换情境、换设问，用于检验同一方法能否迁移
  - 例题按《一地·高考地理核心方法必刷100讲》（2027版）的章节与题型结构自编，不照录原题，不收录原书扫描页
- 139 条细节与拓展：每条考点一条，放在详情页「考法」之后、「例题」之前，补方法边界、易混辨析与迁移方向
- 14 组易混对照 · 38 个地理学发展事件（中国与世界同轴）
- 35 条难度Ⅲ难点卡，覆盖地球运动计算、等压线与气候判读、地质剖面、河流阶地、区位分析模板、资源与粮食安全等高频失分点
- 内容为归纳性表述：不标教材页码、不引用教材原文、不虚构数据与图片；没有把握的内容只写考点归纳

## 打开方式

直接双击 `index.html` 可阅读、检索、做笔记（`file://` 下不注册 Service Worker，其余功能正常）。

完整体验离线缓存，请在站点根目录起本地 HTTP 服务：

```bash
cd geography
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

不要用 `file://` 验收 Service Worker：浏览器只允许在 `http(s)` 下注册。

## 改内容

考点改 `tools/content_source.py`；第 1 道例题改 `tools/examples_source.py`，第 2 道改 `tools/variants_source.py`，拓展改 `tools/extensions_source.py`。不要手改 `data/*.js`：

```bash
python3 tools/build.py
# 期望输出：OK · 5 本书 / 65 课 / 139 条考点 / 278 道例题 / 139 条拓展 / 14 组对照 / 38 个时间线事件
```

`build.py` 会校验：书籍 / 课次 / 条目 id 唯一、课次必须挂到单元、类型合法、难度 1–3、标题 ≤22 字、摘要 ≤60 字、要点 1–8 条、每条要点 ≤90 字、例题必须挂在已存在考点、同一考点最多 3 道例题、每条考点必须有 1 条拓展、时间线阶段与地区合法等。校验失败会直接报错，不生成文件。

改完内容后，把 `index.html`、`detail.html`、`timeline.html` 里的 `?v=20261125f` 统一递增（例如 `20261125g`），并同步修改 `sw.js` 的 `CACHE` 版本（例如 `gg-static-v11`），否则老用户可能继续读到旧缓存。

## 交互

- 三栏：章节树 / 卡片列表 / 详情；移动端折叠为单列，底部「目录 / 列表 / 详情」切换
- 键盘：`/` 聚焦搜索，`j` / `k` 上下切换，`Enter` 打开独立详情页，`Esc` 关闭弹窗、清空搜索或收起移动端抽屉
- 卡片点击与右侧详情联动；刷新后保留当前选中考点
- 搜索、类型/难度/状态筛选、排序、今日待复习都在首屏顺手位置
- 详情页先看「细节与拓展」，再做 2 道例题；答案默认隐藏，点「显示答案与解析」展开
- 详情页可独立打开：`detail.html?id=g1c2-1`，右上角一键复制链接

## 数据与备份

localStorage 键：

| 键 | 内容 |
|---|---|
| `gg.user.v1` | 笔记、状态、复习记录、自定义考点、自定义时间线事件、配置 |
| `gg.snapshots.v1` | 最近 6 个自动快照 |
| `gg.theme` | 明暗主题 |

- 状态：`mastered` 已掌握 / `review` 待复习；「今日已复习」是复习记录，不覆盖掌握状态
- 复习记录：`reviews[itemId] = ['YYYY-MM-DD', ...]`
- 自定义考点 id 前缀 `cu-`，自定义时间线事件 id 前缀 `te-`
- 备份面板：JSON 全量、CSV 笔记表、Markdown 汇总
- 导入：先校验 schema 与字段，再选择「合并」或「覆盖」；两种方式都会先自动快照
- 快照：每日首次打开、导入前、恢复前、清空前自动生成，最多保留 6 个，可回滚

## 离线

首次通过 `http(s)` 打开后，Service Worker 会缓存主站、详情页、时间线、CSS、JS 与三份数据。之后断网：

- `index.html` / `detail.html?id=...` / `timeline.html` 仍可打开
- 笔记、状态、复习与自定义事件仍可读写（本机存储）
- 静态资源采用 stale-while-revalidate：先给缓存，后台更新

## 已知边界

- 不做虚拟滚动：139 条全量渲染，避免「滚动步长与卡片高度不一致」导致的错位
- 不接外部图片 / 字体 CDN：Hero 为内联 SVG 深海浪线与等高线
- 时间线是「地理学发展年表」，不是中国通史 / 世界通史；中国与世界事件同轴，按四阶段着色
- 教材页码、PDF 跳页、书源链接一律不出现
- 例题与拓展为按题型结构自编的同型题和归纳，不收录原书题干、答案或扫描图片；来源只保留章、模块与书名
- 页面数据为本地静态文件，不做账号体系与云端同步
